MyFirst Bank 
1.Opis projekta

MyFirst Bank je web aplikacija za elektronsko bankarstvo.

Cilj projekta je razvoj sigurnog informacionog sistema koji omogućava korisnicima upravljanje bankarskim računima, pregled i izvršavanje finansijiskih transkcija, kao i druge funicionalnosti vezane za elektronsko bankarstvo.

Projekat se satoji iz dva glavna dela:
Backend - REST API koji obradjuju logiku , podatke i sigurnost sistema.
Frontend -React aplikacija preko koje korisnici komuniciraju sa bankarskim sistemom, Klijentska strana!


2.Tehnologije 

Backend:
Node js, Express.js, TypeScript, MongoDB, Mongoose

Frontend:
React, TypeScript, React Router

Sigurnost:
JWT, HTTP-Only Cookies, bcrypt, Helmet, express-validator, express-rate-limit

Ostalo:
Winston, Multer, Git, GitHub
